FOC Repetition Manager

Forensic Repetition Manager

This view creates and manages repetition campaigns. A campaign groups several executions of the same forensic experiment. Each execution produces its own workspace, artifacts, logs, ground truth seal, baseline noise profile, and forensic comparison profile. These profiles are later consumed by the Forensic Reconstruction Comparability View.

Usage Guide

What To Do Here

1. Choose the level. Use Level A if you want to repeat analysis over an existing preserved case. Use Level B if you want repeated controlled incident runs. Use Level C only when redeployment-level reproducibility is part of the objective.
2. Link the source. For Level A, select a preserved base case. For Level B and Level C, provide a scenario context and review the proposed defaults.
3. Review the plan. Check the autogenerated defaults, the pre-flight checklist, and the execution plan before creating the campaign.
4. Create the campaign. This creates the isolated campaign container. It does not yet compare executions.
5. Start or run executions. Use Start Campaign or Run Next Execution to generate execution workspaces and forensic comparison profiles.
Next Steps

What Happens After

After one execution: open the execution workspace or the base-case dashboard and verify that the scientific profiles were generated correctly.
After two or more executions: open the Comparability View and evaluate whether their forensic reconstructions are comparable.
If the campaign is degraded or partial: inspect the Job Status panel, execution warnings, trigger alignment, temporal confidence, and missing profiles before comparing results.
If the scenario ID is missing: Level A can still proceed, but the comparison metadata will be weaker. Level B and Level C should be completed with a valid scenario context before execution.
Scientific rule: this view generates executions. The Comparability View evaluates execution-to-execution stability. The Scientific Lifecycle view explains one execution in depth.

Guided Campaign Assistant

Use this view first to create or register repeated executions. After at least two executions have generated forensic_comparison_profile.json, open the Comparability View to evaluate whether their forensic reconstructions are comparable.

Step 1

Select evaluation level

Choose what kind of repetition you want to create. This determines what will be reused, what will be generated, and what will later be compared.

Step 2

Select source or scenario

The platform proposes a safe source mode automatically. Level A normally links an existing preserved case. Level B and Level C normally require a scenario context.

Comparison Registry Tools

Historical Result Registration

Use this tool only to register previous preserved cases as lightweight result cards in the comparison registry. This does not link the case as evidence for Level B or Level C, and it is not part of creating a campaign.

Register Existing Case As Result Card

Retroactively register a preserved case as a lightweight forensic result card in the comparison registry, without copying any heavy evidence. This computes its comparison_family_id from experimental design fields only.

Background Jobs

Job Status

No active background job. Campaign execution runs as background jobs. When a campaign or execution is started, this panel will show the active stage, job ID, progress, logs and errors.
