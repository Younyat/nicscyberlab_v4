FOC Paper Evidence

          
Reviewer-Facing Paper Evidence Dashboard

          
This dashboard orchestrates paper-oriented scientific evidence packages from real platform outputs. It keeps degraded, partial, missing, and unsupported states visible. Level A runs read-only reanalysis over one preserved case. Level B reuses the repeated incident-execution batch, including nested Level A reports over each fresh case and controlled cleanup of heavy cases so storage does not grow without bound.

        

        

          

          Open Repetition Manager
          Open Scientific Lifecycle
          Open Comparability
        

      

    


    

      

        
What This Runs

        
Level A Paper Evidence

        

          
Runs the existing Level A scientific workflow over one preserved case in read-only mode.

          
Repeats the same dry-run scientific path N times, default 6.

          
Generates a paper package under the dedicated reports directory, including `paper_table_registry.json`, `level_a_report.json`, reviewer-facing markdown, and optional LaTeX/ZIP export.

        

      

      

        
What This Does Not Run

        
Strict Level A Scope

        

          
No new attack.

          
No new acquisition.

          
No scenario redeployment.

          
No modification of the preserved case.

        

      

      

        
Reports Directory

        
Output Root

        
app_core/infrastructure/forensics/paper_evidence/

        
Each package is isolated by report ID and can additionally produce a ZIP export for reviewers.

      

      

        
Level B Path

        
New Cases + Nested Level A

        

          
Runs the existing Level B repetition workflow over one deployed scenario campaign.

          
Each Level B repetition creates a fresh case, runs multilayer analysis, launches nested Level A repetitions over that preserved case, writes reports, and then cleans heavy generated-case artifacts.

          
The batch can clean previous heavy cases before starting so only one heavy case remains active at a time.

FORGE-VI Audit

          
Level C Workflow Metrics Export

          
Generate the full FORGE-VI Level C workflow verification export directly from preserved case artifacts. No reanalysis is run. Produces FORGE-VI_LevelC_Workflow_Checks.csv/json, Operational_Metrics.csv, Reconstruction_Metrics.csv, Comparison_Metrics.csv, Paper_Tables.tex, and Field_Source_Map.csv. Every field carries its exact source file and source key. Missing fields are marked missing_from_existing_reports — not inferred.

          

            
            
          

          

          

        


        

          
FORGE-VI Audit

          
CPR Edge Matrix Export

          
Generate the CPR edge-by-edge matrix from on-disk artifacts. Reads forensic_comparison_profile.json, causal_graph.json, and reconstruction_metrics.json for each execution. Produces CPR_Edge_Matrix.json/csv, CPR_Aggregate.json, CPR_Interpretation.md, and per-execution diagnostics. CPR appears only as a reconstruction diagnostic metric — not as a global workflow metric.
